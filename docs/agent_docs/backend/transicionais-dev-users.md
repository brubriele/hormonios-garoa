# Usuários de teste

**Senha de todos: `Dev@2026-tr@s`** (`SENHA_DOS_USUARIOS`). Dois por papel, para que um teste use um e deixe o outro de controle, e
para dar à interface uma credencial de cada situação sem precisar procurar no banco.

| Papel | Logins | Situação |
|---|---|---|
| Liderança da organização | `admin1`, `admin2` | papel `admin`, enxerga a organização inteira |
| Liderança de naipe | `moderador1`, `moderador2` | papel `manager`, responde por um grupo |
| Membro ativo | `membro1`, `membro2` | papel `user`, dentro de um naipe e com presença registrada |
| Convidado | `convidado1`, `convidado2` | vínculo `PENDING`, convite em aberto sem confirmação |
